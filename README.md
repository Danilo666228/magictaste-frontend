# 🥟 MagicTaste Frontend

> Современный веб-сайт для производителя натуральных пельменей и вареников

## 📋 О проекте

**MagicTaste** — это фронтенд-приложение для компании, специализирующейся на производстве высококачественных пельменей и вареников. Проект создан с акцентом на современный дизайн, производительность и удобство использования.

### ✨ Особенности

- 🎨 **Современный UI/UX** - Красивый и интуитивно понятный интерфейс
- 📱 **Адаптивный дизайн** - Идеально работает на всех устройствах
- ⚡ **Высокая производительность** - Быстрая загрузка и отзывчивость
- 🗺️ **Интеграция с картами** - Яндекс.Карты для отображения местоположения
- 🔄 **Real-time обновления** - Актуальная информация о продукции
- 📞 **Удобные контакты** - Легкий способ связаться с компанией

## 🎯 Основные функции

### 🏆 Секция преимуществ

- Отображение ключевых преимуществ производства
- Интерактивные карточки с hover-эффектами
- Адаптивная сетка для разных устройств

### 📍 Контактная информация

- Интеграция с Яндекс.Картами
- Отображение всех способов связи
- Адаптивный дизайн для мобильных устройств

### 🎨 UI/UX особенности

- Современная типографика
- Плавные анимации и переходы
- Система дизайна на основе Tailwind CSS
